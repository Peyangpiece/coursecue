Mac 版のダウンロード

Apple シリコン用（M1 以降） Intel 用

どちらか分からないときは、画面左上の Apple メニュー →この Mac についてを開きます。「チップ」に Apple M1・M2 などと表示されていれば Apple シリコン用、「プロセッサ」に Intel と表示されていれば Intel 用です。

インストールの手順

  1. ダウンロードした .dmg を開く

    「ダウンロード」フォルダの saboro の .dmg をダブルクリックします。

  2. 「アプリケーション」に入れる

    開いたウインドウで、saboro のアイコンを「Applications（アプリケーション）」フォルダへドラッグします。

  3. はじめて開く

    「アプリケーション」フォルダの saboro を開きます。SaBoRo は Apple の公証を受けていないため、はじめて開くときは止められます。次の手順で開いてください。

    • 「開けません」などの確認が出たら完了を押す
    • システム設定 →プライバシーとセキュリティを開き、下のほうにある saboro の項目のこのまま開くを押す
    • 確認が出たら、Mac のパスワードを入れて開く

    2 回目からはそのまま開けます。開くとメニューバーに常駐し、Mac にログインしたときに自動で起動します。

  4. はじめの設定をする

    初回は manabo を操作するためのブラウザを取り込むため、数分かかります。終わると「はじめの設定」の画面が開くので、次の 3 つを済ませます。

    • manabo のログイン ID とパスワードを保存する（このパソコンの中にだけ暗号化して保存します）
    • SaBoRo課題サポートが「使えます」になっていることを確かめる（設定は要りません）
    • saboroを接続 を押す

    接続すると、授業・課題・締切・資料が manabo から自動で集まります。

アップデート

新しい版が出ると案内の画面でお知らせします。今すぐ更新（またはメニューバーの saboro の新しい版に更新）を押すと、新しい版をダウンロードし、saboro をいったん終了して入れ替えてから自動で開き直します。設定や資料はそのまま残ります。自動で入れ替えられなかったときは案内が出るので、.dmg を開き、手順 2 と同じように「アプリケーション」に入れ直してください。

Windows をお使いの方は Windows 版のダウンロード へ。
