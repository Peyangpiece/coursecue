Windows 版のダウンロード

Windows 版をダウンロード（64 ビット）

Windows 10・11（64 ビット）に対応しています。

インストールの手順

  1. ダウンロードした .exe を開く

    「ダウンロード」フォルダの saboro の .exe をダブルクリックします。

  2. 確認の画面が出たら「実行」する

    SaBoRo はコード署名をしていないため、「Windows によって PC が保護されました」と表示されることがあります。

    • 詳細情報を押す
    • 表示された実行を押す

  3. インストールが終わるのを待つ

    管理者の権限は要りません。インストールは自動で進み、終わると SaBoRo が起動します。タスクトレイに常駐し、Windows にサインインしたときに自動で起動します。

  4. はじめの設定をする

    初回は manabo を操作するためのブラウザを取り込むため、数分かかります。終わると「はじめの設定」の画面が開くので、次の 3 つを済ませます。

    • manabo のログイン ID とパスワードを保存する（このパソコンの中にだけ暗号化して保存します）
    • SaBoRo課題サポートが「使えます」になっていることを確かめる（設定は要りません）
    • saboroを接続 を押す

    接続すると、授業・課題・締切・資料が manabo から自動で集まります。

アップデート

Windows 版は、新しい版が出ると自動で更新されます。設定や資料はそのまま残ります。

Mac をお使いの方は Mac 版のダウンロード へ。
